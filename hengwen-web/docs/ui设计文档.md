## **0. 设计总纲**

衡文（衡量、审阅文章）的本质是**严谨的评判**。它的界面不该喧哗，而应像一位审稿人：安静、专注、值得信任。

一句话定义本设计系统：

> **把纸面的秩序感带入数字审阅——留白即语气，克制即权威。**

三条不可动摇的底线：

1. **一屏一焦点** —— 每个界面只回答一个问题，其余全部后退。
2. **空间代替装饰** —— 用留白与节奏建立层级，不用颜色、阴影、图标堆砌。
3. **克制即专业** —— 所有效果（色彩、动效、圆角、阴影）都要能说出"为什么"。

---

## **1. 品牌气质定位**

**维度定位说明**气质学术审稿人严谨、公正、克制，像期刊编辑部情绪安静、专注用户带着焦虑来，界面要给出秩序感隐喻纸与墨暖白纸面 + 墨色文字，弱化"数码感"反差允许一处"点睛"全站仅一个强调色，且使用面积 ≤ 5%

**设计关键词（审美词库）**：
`留白` `纸感` `墨色` `低饱和` `单点强调` `线性秩序` `克制动效` `学术克制` `呼吸节奏`

## **2. 色彩系统**

> 原则：**低饱和、带灰调、暖中性**。所有颜色都像"掺了纸色的墨"，避免纯黑纯白与荧光感。

### **2.1 基础色板**

**Token色值用途**`--bg-paper#FBFAF8`页面底色（暖白，纸感）`--bg-surface#FFFFFF`卡片/面板表面`--bg-subtle#F4F2EE`次级区域、输入框底色`--bg-hover#F0EEE9`hover 底色`--text-primary#1C1B19`主文字（墨色，非纯黑）`--text-secondary#5C5953`次级文字`--text-tertiary#8A867E`辅助说明、占位符`--text-disabled#B4B0A8`禁用态`--border-default#E6E3DD`默认边框（1px）`--border-strong#D4D0C8`强调边框、分割

### **2.2 强调与语义色（全部低饱和）**

**Token色值用途使用面积**`--accent#3E5C76`**全站唯一强调色**（黛蓝）≤ 5%`--accent-hover#334D63`强调色 hover—`--accent-bgrgba(62, 92, 118, 0.08)`强调色底色（选中项）—`--success#5B7261`通过、合规（松绿）≤ 2%`--warning#A9813B`存疑、建议（赭金）≤ 2%`--error#A34A3E`违规、必须修改（绛红）≤ 2%`--error-bgrgba(163, 74, 62, 0.08)`错误底色—

> **校准规则**：语义色只在"状态需要被看见"时出现；错误红色不得作为按钮主色大面积使用。
> 深浅色模式：深色模式底色取 `#17161A` 系，所有色值按明度映射（文档后附映射表）。

### **2.3 禁用清单（批判与精炼者的红线）**

- ✗ 渐变（任何形式，含按钮渐变）
- ✗ 高饱和荧光色（如 `#FF5722`、`#00E5FF`）
- ✗ 同一屏超过 3 种语义色同时出现
- ✗ 纯黑 `#000000` 作大面积背景
- ✗ 霓虹色/渐变用于得分、进度等数据可视化

## **3. 字体系统**

> 原则：**中文字体为主，克制变化。** 字重只允许 400 / 500 / 600 三档，禁止 700+ 大面积使用。

### **3.1 字体栈**

```
--font-sans: "Inter", "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", system-ui, sans-serif;
--font-serif: "Source Han Serif SC", "Noto Serif SC", "Songti SC", serif;  /* 仅品牌字/报告标题 */
--font-mono: "JetBrains Mono", ui-monospace, "SF Mono", monospace;          /* 仅代码/编号/得分数字 */
```

### **3.2 字号阶梯（Type Scale，1.25 比例）**

**层级字号/行高字重用途**Display34px / 1.3500报告大数字、结果页主标题（宋体可用）H126px / 1.4500页面主标题H220px / 1.45500区块标题H316px / 1.5600卡片标题、问题条目Body15px / 1.7400正文（**中文行高 ≥ 1.7，呼吸感的关键**）Secondary13px / 1.6400辅助说明Caption12px / 1.5400时间戳、标签

### **3.3 排版纪律**

- 正文行高 **1.7–1.8**，段落间距 ≥ 16px —— 这是"呼吸感"的主要来源。
- 全站字距（letter-spacing）默认 0；标题可 -0.5px，不得更紧。
- 中文正文一律不加粗、不斜体（斜体留给外文文献名）。
- 数字与得分用等宽字体，保证对齐与"仪器感"。

---

## **4. 间距与网格（呼吸感的结构核心）**

### **4.1 基准**

- 采用 **8pt 网格**，所有间距取 8 的倍数。
- 页面安全边距（padding）：**桌面 48px，平板 32px，移动 20px**。
- 区块垂直节奏：`96 → 64 → 48 → 32 → 24 → 16 → 8`。

### **4.2 核心间距 Token**

**Token值典型用途**`--space-1`8px图标与文字间隙`--space-2`16px行内元素间距、表单标签间距`--space-3`24px卡片内部 padding、列表行距`--space-4`32px卡片之间、区块之间`--space-5`48px大区块分隔、页首下方`--space-6`64px页面主区块分隔（首屏）`--space-7`96px首屏 hero 区域留白

### **4.3 呼吸感执行规则**

1. **边框让位给间距** —— 两个区块之间优先用 32px 空白分隔，而不是画线；确需分隔时用 1px `-border-default`，且仅用于水平全宽分割。
2. **卡片留白下限** —— 卡片内边距不得小于 24px；内容稀少时宁可放大卡片也不堆内容。
3. **列表行高** —— 列表/表格行高 ≥ 48px；问题清单条目行高 56px。
4. **信息密度上限** —— 每屏可视条目 ≤ 7 条，超出进入分页/滚动视图而非压缩行距。
5. **首屏即呼吸** —— 首页首屏只放：品牌名 + 一句话说明 + 上传区（居中的留白容器），其他全部下移。

## **5. 形状、边框与阴影**

**元素规范**圆角（小元素）4px（输入框、按钮、标签）圆角（容器）8px（卡片、面板）上限 —— **不做 >12px 的圆角，拒绝"胶囊感"**边框1px `--border-default`，不使用 2px 以上的可见边框阴影仅一层：`0 1px 2px rgba(28,27,25,0.04), 0 4px 12px rgba(28,27,25,0.06)`（纸面投影，浮起感极轻）选中态2px 边框 + `--accent` 或 `--accent-bg` 底，不用描边阴影组合

## **6. 组件规范（Ant Design 6 定制方向）**

> 基于 antd v6 Token 机制定制（`ConfigProvider` + `theme.token`），不写散装 CSS。

**组件定制要点Button**主按钮：`--accent` 实心白字，圆角 4，高 40px；次按钮：描边 `--border-strong`；文字按钮：无边框。**一屏最多一个主按钮Card**白底、1px 淡边框、8px 圆角、padding 24–32；不用默认 header 底纹**Input / TextArea / Upload**高 40–44px，底色 `--bg-subtle`，聚焦时 2px `--accent` 边框（不发光）**Upload（核心）**大留白容器：padding 64px，虚线边框 1.5px `--border-strong`，hover 变 `--accent`；图标弱化，文字为主**Table**去斑马纹、去竖向边框；表头 13px 次级色；行高 48px；hover 仅 `--bg-hover`**Tag / 状态**底色 = 语义色 8–12% 透明度，文字用语义色深一档；不加描边**Progress / 得分**得分数字用 Display 级 + 等宽字体；进度条 4px 高，仅 `--accent`，不用渐变与圆头动画**Tabs**仅下划线式（`type="line"`），选中线 2px `--accent`**Empty**居中，留白 ≥ 64px，图标单色 40px，文案 15px 次级色**Message / 通知**左上角低调出现，白底淡边，无彩色图标框**Drawer / Modal**padding 32px，标题 20px，遮罩 `rgba(28,27,25,0.28)`

## **7. 核心页面设计**

### **7.1 首页（上传/工作台）—— 极简入口**

```
┌──────────────────────────────────────────────┐
│  衡文                                          │  ← 品牌：宋体 20px，仅此一处可用宋体
│                                              │
│                                              │
│        「衡量，然后修改」                      │  ← 一句话说明，次级色，大留白
│                                              │
│   ┌────────────────────────────────────┐     │
│   │                                    │     │
│   │   拖拽文档至此，或点击选择文件        │     │  ← 上传区：padding 64，虚线边框
│   │   （支持 .docx / .pdf / .md）        │     │
│   │                                    │     │
│   └────────────────────────────────────┘     │
│                                              │
│   最近检查（3–5 条，轻量列表）                 │
│                                              │
└──────────────────────────────────────────────┘
```

- 首屏不出现任何功能按钮（除上传），导航仅保留：首页 / 历史 / 设置。
- 品牌字 20px 宋体，无 logo 图形 —— **名字本身就是品牌**。

### **7.2 分析中 —— 安静的等待**

- 居中：4px 高的细进度条（`-accent`，无动画花哨）+ 当前阶段文字（"正在检查格式规范…"）。
- 不做转圈 loading、不做百分比弹跳、不做全屏遮罩。
- 允许用户离开页面，返回后恢复进度（状态提示即可）。

### **7.3 报告页 —— 克制的数据展示**

```
┌────────────────────────────────────────────────┐
│  论文标题（Display 级，宋体）                     │
│  论文.docx · 检查于 2026-08-08 14:32 · 12,480 字 │  ← 13px 次级色
│                                                │
│  ┌──────────────┬─────────────────────────────┐ │
│  │  规范得分     │  问题清单（按严重度分组）      │ │
│  │              │                             │ │
│  │    87        │  ● 必须修改    3             │ │  ← 绛红，≤2%
│  │   /100       │  ◐ 建议修改    7             │ │  ← 赭金
│  │  [─── 87 ──] │  ○ 仅供参考    12            │ │  ← 次级色
│  │              │                             │ │
│  │  通过         │  （条目行高 56px）           │ │
│  └──────────────┴─────────────────────────────┘ │
│                                                │
│  修改建议对照（原文 → 建议）                     │
└────────────────────────────────────────────────┘
```

- 得分区：大数字（86px 等宽字体）+ 细进度条 + 一个词的结论（"通过 / 存疑 / 需修改"），**不画雷达图、环形图**。
- 问题条目：严重度点 + 标题 + 位置（"§2.3 · 第 47 行"）+ 一行摘要；点击展开对照视图。
- 对照视图：左原文右建议，中间用 1px 分隔线；删除用绛红删除线，新增用松绿，各 ≤2% 面积。

### **7.4 历史记录 —— 列表即全部**

- 表格：文件 / 类型 / 得分 / 状态 / 时间，行高 48px，去斑马纹。
- 得分列用等宽字体，状态用 Tag。
- 不设筛选器的空状态也保持大留白。

### **7.5 设置页 —— 表单的克制范本**

- 分组间距 48px；标签 14px；输入框统一高 40px。
- 所有开关（Switch）默认关闭态即"安全态"。

## **8. 动效规范**

> 原则：**150–240ms，一档缓动，只做反馈不做表演。**

**场景时长缓动说明**hover / active120–150ms`ease-out`背景、边框色变化面板展开 / 折叠200ms`ease-out`高度过渡页面切换240ms`ease-out`8px 上移 + 淡入得分数字600ms`ease-out`仅滚动数字，不弹跳问题条目出现240ms`ease-out`从上往下依次淡入，间隔 40ms

**红线**：

- ✗ 弹性 / 弹簧动画（`bounce`、`spring`）
- ✗ 无限循环动画（loading 转圈除外，但本项目用进度条替代）
- ✗ 视差、悬浮粒子、背景动画
- ✓ 完整支持 `prefers-reduced-motion: reduce`（全部降为 0ms 或仅淡入）

## **9. 反模式清单（验收时的否决项）**

设计实现后，出现以下任何一项即视为**违背本设计系统**：

1. 页面出现渐变、玻璃拟态、大投影。
2. 一屏出现两个以上"主按钮"或两个强调色。
3. 列表行高 < 40px，或卡片 padding < 20px。
4. 弹窗遮罩过深（> 0.4）或出现模糊背景。
5. 任何 emoji 作为功能图标；装饰性图标无 40px 以上留白。
6. 得分页使用环形图、雷达图、3D 效果。
7. 中文正文行高 < 1.6。
8. 出现"AI 炫技"式文案（"智能分析中，请稍候…"改为"正在检查格式规范…"）。

## **11. 深色模式（简则）**

- 底色：`#17161A` / 卡片 `#1E1D22` / 文字 `#EDEAE4`。
- 语义色按明度上调一档（如 `-error → #C46758`），透明度类 Token 不变。
- 其余规则（间距、动效、反模式）完全一致 —— **深色模式不是另一种设计**。
